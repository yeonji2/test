# 손글씨 방명록

행사장에서 참가자가 태블릿이나 휴대폰에 손으로 방명록을 쓰고 **남기기**를 누르면, 대형 화면(TV·프로젝터)에 그 방명록이 전체화면으로 떠오르는 웹 앱입니다.

## 화면 구성

| 주소 | 용도 |
| --- | --- |
| `index.html` | 시작 화면: 이 기기를 작성용 또는 전시용으로 고릅니다 |
| `index.html#write` | 작성용: 펜 색 6가지, 굵기 3단계, 되돌리기, 모두 지우기, 남기기 |
| `index.html#display` | 전시용: 새 방명록을 전체화면으로 띄우고, 평소에는 방명록 벽과 휴대폰 참여 QR 코드를 보여줍니다 |

## 저장 방식

- **claude.ai 아티팩트로 열면:** 아티팩트의 공유 데이터베이스(`db` 기능)에 저장됩니다. 여러 기기가 실시간으로 연결돼요.
  - `entries` 컬렉션: 방명록 이미지
  - `config/event` 문서: 행사 이름, 안내 문구, 전체화면 표시 시간, QR 표시 여부
- **이 파일만 브라우저로 열면:** 기기 안에서만 동작합니다. `BroadcastChannel`으로 같은 브라우저의 탭끼리만 연결되고, 새로고침하면 목록이 사라집니다.

방명록은 16:10 비율의 손글씨 이미지(WebP 또는 JPEG)로 저장되며, 문서 한 개당 크기 제한(256KiB) 안에 들어가도록 자동으로 압축됩니다.
